## 5. Root Cause
The summary endpoint's implementation attempts to compute an average by dividing by len(orders) without checking for an empty orders list. When no orders are present, len(orders) is zero and the division raises ZeroDivisionError, causing the request to fail with a 500 error.

This is a code defect (application logic) — missing input/state validation and handling for an empty result set in api/app.py.
