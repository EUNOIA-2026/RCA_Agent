## 5. Root Cause
The summary endpoint computes an average with "average = total / len(orders)" without guarding against an empty orders list. When the service received a request and the orders collection was empty (len(orders) == 0), the handler attempted to divide by zero which raised an unhandled ZeroDivisionError and caused a 500 response.

This is the root cause because the log shows the exception originates directly from that line in app.py and no upstream error or infrastructure failure precedes it.
